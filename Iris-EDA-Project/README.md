# 🌸 Iris Exploratory Data Analysis (EDA)

## Project Overview

This project explores the famous Iris flower dataset using Python and Exploratory Data Analysis (EDA). The goal is to understand the relationships between flower measurements and species through statistical summaries and visualizations.

---

## Objectives

- Explore the Iris dataset
- Clean and inspect the data
- Perform descriptive statistics
- Visualize feature distributions
- Analyze relationships between variables

---

## Dataset

The dataset contains 150 observations of Iris flowers with four numerical features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

Target Variable:

- Species
  - Setosa
  - Versicolor
  - Virginica

## Exploratory Data Analysis

The analysis includes:

- Dataset overview
- Data types inspection
- Summary statistics
- Missing value check
- Histograms
- Boxplots
- Pairplots
- Correlation analysis

---

## Key Insights

- No missing values were found.
- Setosa is clearly separable from the other species.
- Petal Length and Petal Width are strongly correlated.
- Sepal measurements show greater overlap among species.

---

## Conclusion

The Iris dataset is well suited for exploratory analysis and machine learning. The visualizations reveal clear patterns that can be used for classification tasks.
