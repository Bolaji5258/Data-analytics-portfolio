Iris Dataset Exploratory Data Analysis (EDA)¶

Objective¶

Analyze the Iris dataset to understand species distribution, feature relationships, and key statistical patterns.

Dataset¶

  • 150 observations
  • 5 columns
  • 3 species:
    • Setosa
    • Versicolor
    • Virginica

Key Findings¶

  • No missing values were found.
  • 3 duplicate records were removed.
  • Petal length and petal width have a very strong positive correlation.
  • Setosa has significantly smaller petal measurements than the other species.

Conclusion¶

The Iris dataset was successfully analyzed using exploratory data analysis techniques. The dataset contained no missing values, and 3 duplicate records were removed. Petal length and petal width showed a strong positive correlation. Setosa flowers had noticeably smaller petal measurements compared to Versicolor and Virginica.

IRIS DATASET EDA REPORT

Objective:
To explore and analyze the Iris dataset using Python and Pandas.

Data Cleaning:
- Dataset initially contained 150 rows and 5 columns.
- No missing values were found.
- Three duplicate records were identified and removed.
- Final dataset contains 147 rows and 5 columns.

Key Findings:
1. The dataset contains three flower species:
   - Setosa
   - Versicolor
   - Virginica

2. Petal length and petal width have a very strong positive correlation (0.96).

3. Virginica flowers have the highest average petal length and petal width.

4. Setosa flowers have the smallest petal measurements.

5. Histogram analysis shows petal lengths are grouped into distinct ranges, indicating clear differences among species.

6. Scatter plot analysis confirms that larger petal lengths are associated with larger petal widths.

Conclusion:
The Iris dataset is clean, well-structured, and suitable for exploratory analysis and machine learning applications.
