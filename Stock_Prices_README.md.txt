# Stock Prices Exploratory Data Analysis (EDA)

## Project Overview

This project analyzes historical stock market data using Python and exploratory data analysis (EDA) techniques. The goal is to uncover trends, relationships, and trading patterns within the dataset.

## Objective

To explore stock price behavior and trading activity by analyzing:

- Stock price trends
- Trading volume patterns
- Correlations between variables
- Distribution of stock prices
- Data quality and missing values

## Tools Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- GitHub

## Dataset Information

- 497,461 records
- Columns:
  - Symbol
  - Date
  - Open
  - High
  - Low
  - Close
  - Volume

## Analysis Performed

### Data Inspection
- Loaded and explored the dataset
- Reviewed data structure and column types

### Data Quality Check
- Checked for missing values
- Generated descriptive statistics

### Trading Volume Analysis
- Identified the top 10 stocks by total trading volume

### Trend Analysis
- Visualized Apple (AAPL) closing price trend over time

### Correlation Analysis
- Calculated correlations between numerical variables
- Created a correlation heatmap

### Distribution Analysis
- Examined the distribution of closing prices

## Key Findings

1. Apple (AAPL) showed a strong upward trend in closing prices.
2. BAC recorded the highest trading volume among analyzed stocks.
3. Open, High, Low, and Close prices are highly correlated.
4. Trading volume has a weak correlation with stock prices.
5. The dataset contains only a small number of missing values.
6. Closing prices are right-skewed, with most stocks concentrated in lower price ranges.

## Conclusion

The analysis provides valuable insights into stock price behavior and trading activity. Strong relationships were observed among price variables, while trading volume showed relatively weak correlation with stock prices.
