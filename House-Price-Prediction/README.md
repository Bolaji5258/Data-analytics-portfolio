# 🏠 House Price Prediction using Python

## 📌 Project Overview

This project explores the Boston Housing dataset using **Exploratory Data Analysis (EDA)** and **Machine Learning**. The goal is to understand the factors that influence house prices and build a Linear Regression model capable of predicting the median value of homes based on housing characteristics.

---

## 🎯 Objectives

- Perform Exploratory Data Analysis (EDA)
- Clean and prepare the dataset
- Analyze feature relationships using correlation analysis
- Visualize important trends and distributions
- Train a Linear Regression model
- Evaluate model performance
- Save the trained model for future predictions

## 🤖 Machine Learning Model

Model Used:

**Linear Regression**

The model was trained to predict the median value of owner-occupied homes using the available housing features.

---

## 📏 Model Evaluation

The model performance was evaluated using standard regression metrics including:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

These metrics were used to assess how accurately the model predicts house prices.

---

## 💾 Model Export

The trained model was saved as:

```
house_price_model.pkl
```

This allows the model to be loaded later for prediction without retraining.

---

## 🔍 Key Findings

- Houses with a higher average number of rooms generally have higher prices.
- The **LSTAT** feature has a strong negative relationship with house prices.
- Several housing characteristics show significant correlations with the target variable.
- The dataset contains no missing values, making it suitable for machine learning without extensive preprocessing.
